# Power-BI-Data-Visualization-Project-Global-Superstore-Dataset
Power BI Data Visualization Project – Global Superstore Dataset 📊


I recently worked on building an interactive dashboard in Power BI using the Global Superstore dataset. The goal was to turn raw data into meaningful insights that help in business decision-making.

✅ Key Highlights of the Dashboard:

KPIs: Total Sales, Quantity Sold, Average Delivery Days, and Return Orders

Year-wise Analysis (2012–2015) with interactive filters

Top Product Performance visualized by sales contribution

Integrated visuals to track sales trends, customer demand, and return patterns

This project helped me strengthen my skills in:
🔹 Data cleaning & transformation in Power Query
🔹 DAX measures for KPI calculations
🔹 Building visually appealing & interactive dashboards
🔹 Storytelling with data for better decision support
